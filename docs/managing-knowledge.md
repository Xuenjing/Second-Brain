# Managing Knowledge

Second Brain includes tools for reviewing, searching, editing and removing information stored in the local knowledge base.

## Open the knowledge base

Select **View knowledge entries** from the toolbar.

The knowledge view can display either:

- individual knowledge entries
- grouped sources

This makes it easier to inspect both specific pieces of information and the files they came from.

## Search saved knowledge

Use the search field to find stored information.

Search matches can include both:

- knowledge text
- source names

This is useful when the knowledge base contains many imported files or manually added entries.

## Filter entries

The knowledge view can filter entries by source type.

Available filters include:

- TXT
- DOCX
- PDF
- email
- manually added knowledge

You can combine filtering with search to narrow the results further.

## Sort entries

Knowledge entries can be sorted by date.

You can choose to display:

- newest entries first
- oldest entries first

## View sources

Switch to the source view to see imported knowledge grouped by source.

A source can represent, for example:

- a TXT file
- a DOCX document
- a PDF document
- an imported email

Selecting a source allows you to inspect the entries associated with that file.

## Edit knowledge

Individual knowledge entries can be edited.

Select the edit control for an entry, update the text and save your changes.

Second Brain updates the stored information and creates a new embedding for the edited text so that it can continue to be retrieved correctly when asking questions.

## Delete a knowledge entry

Individual entries can be removed from the knowledge base.

Second Brain asks for confirmation before deleting the selected entry.

Deleted knowledge will no longer be available when answering questions.

## Delete a source

You can also delete all knowledge associated with an imported source.

This is useful if:

- a document is outdated
- the wrong file was imported
- you want to replace a source with a newer version

Deleting a source removes all knowledge entries associated with that source.

This action cannot be undone.

## Keeping the knowledge base useful

For best results:

- remove outdated information
- avoid unnecessary duplicate information
- review imported or AI-suggested facts before saving them
- keep important information clear and specific

A well-maintained knowledge base makes it easier for Second Brain to retrieve useful information when answering questions.
