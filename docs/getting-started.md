# Getting Started

This guide explains the basic workflow in Second Brain.

## Start the application

Launch Second Brain and wait for the local embedding model and language model to load.

When the application is ready, the main window displays:

- the chat area
- the question input field
- controls for adding and managing knowledge
- model selection
- access to settings

## The basic workflow

A typical Second Brain workflow consists of four steps:

1. Add or import knowledge.
2. Review the information before saving when applicable.
3. Ask a question about the stored information.
4. Inspect the sources used to generate the answer.

## Add your first knowledge entry

Select **Add knowledge** from the toolbar.

You can either:

- enter information manually
- import a TXT file
- import a DOCX document
- import a PDF document
- import an EML or MSG email

For supported documents and emails, Second Brain may also provide AI-assisted analysis that suggests factual passages for you to review before saving.

## Ask your first question

After knowledge has been added, type a question in the chat input and select **Send**.

Second Brain retrieves relevant information from the local knowledge base and provides it to the selected language model.

When sources are available, they can be inspected from the answer.
